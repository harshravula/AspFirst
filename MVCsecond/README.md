# ASP.NET Core MVC Learning Project

## Overview
This project is developed to understand the fundamentals of ASP.NET Core MVC and how web applications process HTTP requests.

## Technologies Used
- C#
- ASP.NET Core MVC
- HTML
- Git and GitHub

## Concepts Implemented
- MVC Architecture (Model, View, Controller)
- Controllers and Action Methods
- HTTP GET and POST methods
- Model Binding
- ViewData
- HTML Forms
- Routing

## Project Structure
- Controllers: Handles incoming HTTP requests.
- Models: Defines application data and properties.
- Views: Contains the user interface using Razor and HTML.
- wwwroot: Contains static files such as CSS and JavaScript.

## Purpose
This project is part of my practical learning journey in ASP.NET Core MVC, focusing on understanding how client requests are processed and how data is transferred between Views, Controllers, and Models.
